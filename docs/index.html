Unsere Spule: Radius R = 30 mm, je 330 Windungen. Bei Abstand = Radius ist es eine echte Helmholtz-Spule.

2 · Warum gerade diese Spule?

Bei einer Helmholtz-Spule kann man das Feld in der Mitte genau ausrechnen, ohne es zu messen:

B = (4/5)3/2 · μ₀ · N · I / R

μ₀ = Naturkonstante · N = Windungen · I = Strom · R = Radius

Und: Rund um die Mitte ist das Feld fast überall gleich stark. Sitzt der Sensor ein paar Millimeter daneben, misst er trotzdem fast denselben Wert. Probier oben, den Abstand zu verändern: Der gleichmäßige Bereich wird dann viel kleiner.

3 · Kalibrier den Sensor!

Jeder Sensor misst ab Werk ein bisschen falsch. Unser simulierter Sensor auch. So findest du heraus, um wie viel:

  1. Stell oben eine Stromstärke ein.
  2. Tipp auf Messpunkt aufnehmen. Der Sensor misst, die Formel liefert den richtigen Wert.
  3. Wiederhole das bei 3–4 verschiedenen Strömen, dann Kalibrieren.
